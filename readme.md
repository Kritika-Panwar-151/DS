# Data Structures Programs in C  
**B.E. Engineering – Semester 3**

- This repository contains Data Structures programs implemented in C
- Developed as part of B.E. Semester 3 Data Structures coursework
- Covers fundamental data structures and algorithms

---

## Course Information
- **Course Name**: Data Structures
- **Semester**: 3
- **Degree**: B.E. Engineering
- **Programming Language**: C
- **Type**: Academic / Lab Programs

---

## Programs Included

### Stack
- `1_Stack.c` – Basic stack operations
- `Stack_BalanceParenthesis.c` – Parenthesis balance checking
- `Stack_ComputePostfix.c` – Postfix expression evaluation

### Expression Conversion
- `2_InfixToPostfix.c` – Infix to Postfix conversion using stack

### Queue
- `3a_LinearQueue.c` – Linear Queue
- `3b_CircularQueue.c` – Circular Queue
- `CircularQueue_DoubleEnded.c` – Double Ended Queue (Deque)
- `LinearQueue_PrioritySort.c` – Priority Queue using Linear Queue
- `CircularQueue_PrioritySort.c` – Priority Queue using Circular Queue

### Singly Linked List
- `4_SinglyLinkedList_Insert.c` – Insertion operations
- `5_SinglyLinkedList_Delete.c` – Deletion operations
- `6a_SinglyLinkedList_Sort_Reverse_Concatenation.c` – Sorting, reversing and concatenation
- `6b_SinglyLinkedList_Stack&Queue.c` – Stack and Queue using linked list

### Doubly Linked List
- `7_DoublyLinkedList.c` – Doubly linked list operations
- `DoublyLinkedList_DeleteByPos.c` – Delete node by position

### Trees
- `8_BinarySearchTree_Insertion&Traversal.c` – BST insertion and traversal
- `BinarySearchTree_Insertion_Deletion.c` – BST insertion and deletion

### Graph Traversal
- `9a_BFS.c` – Breadth First Search (BFS)
- `9b_DFS.c` – Depth First Search (DFS)

### Hashing
- `10_Hashing.c` – Hash table implementation
